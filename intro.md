# 實作工作坊：運用 GitHub Copilot 與 Microsoft Foundry 打造 Agent Harness

## 中文版

### 課程大綱

本工作坊將帶領學員運用 GitHub Copilot、Copilot SDK 與 Microsoft Foundry，建立可串接模型、知識與工具的 Agent Harness。透過 Demo 與 Hands-on Lab，學員將完成 Agent instructions、Custom Tool、資料分析及執行結果觀測。

實作情境可依活動需求調整為 AI usage optimization、SDLC analysis、engineering assistant 或其他企業 Agent use case。

### 課程重點

- 了解 Agent Harness 的架構與運作方式
- 使用 GitHub Copilot 與 Copilot SDK 加速 Agent 開發
- 串接模型、知識來源、Custom Tools 與 MCP
- 使用 Microsoft Foundry 觀測及評估 Agent 行為
- 認識 human-in-the-loop 與企業治理設計
- 快速展示 Foundry IQ 的企業知識查詢能力

### 注意事項

- 請自備可連接網路的筆記型電腦與充電器
- 請準備 GitHub 帳號並確認 GitHub Copilot 使用權限
- 請依實作指南準備 Visual Studio Code、Git 及指定 Runtime
- 測試環境、starter project 與範例資料將由主辦單位提供
- 請勿上傳公司機密、個人資料、API Key 或正式環境資料
- Foundry IQ 以講師 Demo 為主，實際內容將依活動環境調整

# Hands-on Workshop: Build an Agent Harness with GitHub Copilot and Microsoft Foundry

## English Version

### Course Outline

This workshop introduces how to build an Agent Harness with GitHub Copilot, the Copilot SDK, and Microsoft Foundry. Through demonstrations and hands-on exercises, participants will configure agent instructions, add a Custom Tool, analyze data, and observe agent execution.

The scenario may be adapted to AI usage optimization, SDLC analysis, engineering assistants, or other enterprise agent use cases.

### Workshop Highlights

- Understand the architecture of an Agent Harness
- Accelerate agent development with GitHub Copilot and the Copilot SDK
- Connect models, knowledge sources, Custom Tools, and MCP
- Observe and evaluate agent behavior with Microsoft Foundry
- Introduce human-in-the-loop and enterprise governance
- Demonstrate enterprise knowledge retrieval with Foundry IQ

### Important Information

- Bring a laptop, power adapter, and internet connectivity
- Prepare a GitHub account with access to GitHub Copilot
- Install Visual Studio Code, Git, and the runtime specified in the lab guide
- The organizer will provide the test environment, starter project, and sample data
- Do not upload confidential information, personal data, API keys, or production data
- Foundry IQ will be demonstrated by the instructor, and content may be adjusted based on environment availability
